# ☀️ SolarCare Smart Maintenance

## Smart Solar Maintenance Advisor

SolarCare Smart Maintenance is a web-based prototype designed to monitor solar panel conditions and provide intelligent cleaning recommendations.

## 🚀 Features

- ☀️ Solar Dashboard
- 📡 Hardware Sensor Data Monitoring
- 🌫️ Dust Accumulation Monitoring
- 🌡️ Panel Temperature Monitoring
- 💧 Humidity Monitoring
- ⚡ Voltage and Power Monitoring
- 🧹 AI Cleaning Priority Score
- 🤖 AI Performance Prediction
- 🌦️ 7-Day Weather Forecast
- 🔊 Tamil and English Voice Recommendation
- 💬 Cleaning Alert
- 🧹 Automatic Cleaning Simulation
- 📋 Maintenance History

## 🔧 Technologies Used

- HTML
- CSS
- JavaScript
- ESP32 (Planned Hardware Integration)
- Solar Panel Sensors

## 📡 Hardware Integration

The current version is a software prototype. Sensor values are simulated for demonstration.

In the next phase, sensors will be connected to an ESP32 to collect real-time solar panel data such as:

- Dust accumulation
- Temperature
- Humidity
- Voltage
- Current

The ESP32 will transmit the sensor data to the dashboard through Wi-Fi.

## 🎯 Objective

The main objective of SolarCare is to help solar panel users identify the right time for cleaning and maintain better panel performance.
